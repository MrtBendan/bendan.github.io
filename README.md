# MrtBendan · 每日分享

> 一月一期，每天一份资源清单。
> 这是站长的个人资源备份站：把公开分享里值得收的好东西分条存好，随时翻看。

🌐 **在线访问**：https://mrtbendan.github.io/

## 这是什么

- 每天汇编一份互联网资源分享：软件、工具、网站和有趣的小东西；
- 每条 = 名称（即直达链接）+ 一句编辑自撰的介绍，看一眼就知道它是什么、干什么用；
- 只收资源，广告不收。

## 结构

- **首页**：展示最近一天的分享与全部期数；顶栏有站内搜索（点放大镜，或在页面按 `/` 唤起），可按名称和关键词查遍所有期数；
- **月刊**：一个月为一期，期号自 2026 年 10 月第 1 期起递增；期内按天倒序排列，顶部有日期索引可跳转；
- **某天没有可收的内容就空缺**，不补不凑；首页永远展示最近有内容的一天。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 首页（最新一天 + 期数列表） |
| `YYYY-MM.html` | 各月月刊，如 `2026-10.html` 为第 1 期 |
| `search.json` | 全站搜索索引，随内容每日重建 |
| `style.css` / `search.js` / `ui.js` | 全站样式、搜索与轻交互脚本 |

## 维护方式

- 每天 11:11 自动汇编当日新分享、生成静态页并发布到 GitHub Pages；
- 内容先存为结构化数据（JSON）再渲染成页，方便长期积累与检索；
- 本站由 Muse 汇编维护。
